VidSqueeze

Make video and audio files smaller, on your own computer. Nothing is uploaded anywhere.

Get it on GitHub Download the latest release

What it does

VidSqueeze compresses and converts media files. It opens in the browser you already use, and it also works entirely from a terminal. Version 1.14.0.

KindReadsWrites
VideoMP4, MOV, MKV, AVI, WebM, MPEG, WMV, FLV, and moreMP4, MKV, WebM, MOV with H.265, H.264, AV1 or VP9
AudioMP3, M4A, AAC, WAV, FLAC, OGG, Opus, WMA, AIFFOpus, AAC, MP3, FLAC

It needs the internet once, and then never again

On first run VidSqueeze fetches ffmpeg into its own folder. After that you can turn the network off and it keeps working: on a plane, on a train, on a machine that has never been online, or on one you would rather did not talk to anything.

That is the real difference from a converter on the web. Those want the file uploaded first, which puts your holiday videos, your work and your recordings on somebody else's server, subject to their size limits, their queue, their privacy policy, and their decision about how long to keep a copy.

Nothing you convert here leaves the computer, because there is nowhere for it to go. The interface is a small server on your own machine that only your own browser can reach.

Built for long jobs, not just single files

Point it at a folder of sixty videos and it works through them, showing what each one saved. A batch can be paused when you need the machine back and picked up afterwards, and the file being worked on finishes rather than being cut off, so nothing is left half written.

The summary at the end separates the two kinds of result: how many came out smaller, and how many came out larger and would have been better left alone. A run where most files grew usually means the wrong output format, which is worth knowing rather than hiding behind one number.

Getting started

There is nothing to install. No administrator rights are needed, nothing is put anywhere else on your computer, and deleting the folder removes VidSqueeze completely.

1. Download it

Take the latest release and download the Source code (zip) file at the bottom of it. If you would rather have the very newest work, use the green Code button on the repository page and choose Download ZIP.

2. Unpack it somewhere permanent

The zip unpacks into a folder with a long name such as vidsqueeze-1.14.0. Rename it to VidSqueeze, which is tidier, and move it to:

SystemWhere to put it
WindowsC:\Users\<you>\Documents\VidSqueeze
macOS~/Documents/VidSqueeze
Linux~/Documents/VidSqueeze

Not your Downloads folder, and not a temporary one. VidSqueeze keeps the tools it fetches, and by default your converted files, inside its own folder, so it needs to stay put. Keep the folder together as well: the launcher only works from inside it, so move the whole folder rather than dragging the launcher out of it. Make a shortcut if you want one on your desktop.

3. Start it

SystemWhat to click
WindowsDouble click Start VidSqueeze.bat
macOSRight click Start VidSqueeze.command, choose Open, then confirm
LinuxDouble click start-vidsqueeze.sh, or run ./start-vidsqueeze.sh

macOS needs the right click the first time only, because the file came from the internet. After that, double clicking works normally.

VidSqueeze then opens in your browser. On first run it fetches ffmpeg, which it uses to do the encoding, into its own folder. If Python is missing, Windows downloads a private copy of about 11 MB into that folder too, and macOS and Linux tell you the one command that installs it.

If you use git

cd ~/Documents
git clone https://github.com/pxspaces/vidsqueeze.git VidSqueeze
cd VidSqueeze
python3 -m vidsqueeze

Cloning has one advantage worth knowing: when a new version comes out, the Updates button inside the program can pull it for you.

From a terminal

vidsqueeze holiday.mp4                      compress one video
vidsqueeze ~/Videos                         compress a whole folder
vidsqueeze -p whatsapp clip.mov             fit a sharing limit
vidsqueeze -p shrink_to_1080 *.MP4          scale a batch down
vidsqueeze --terminal                       step by step questions
